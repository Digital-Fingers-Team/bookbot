# Environment

All env is validated in `apps/api/src/config/env.ts`; `.env.example` is the template. Grouped:

| Group | Vars |
| --- | --- |
| Server | `PORT`, `NODE_ENV`, `LOG_LEVEL`, `TRUST_PROXY_HOPS`, `CLIENT_ORIGIN`, `PUBLIC_API_URL`, `SENTRY_DSN` |
| Database | `MONGODB_URI` |
| Auth | `AUTH_JWT_SECRET`, `ADMIN_API_KEY`, `DEFAULT_ADMIN_EMAIL`, `DEFAULT_ADMIN_PASSWORD` |
| LLM | `LLM_PROVIDER`, `OPENROUTER_API_KEY`, `OPENROUTER_BASE_URL`, `OPENROUTER_MODEL`, `LOCAL_LLM_*` |
| Embeddings | `EMBEDDING_PROVIDER`, `OPENROUTER_EMBEDDING_MODEL`, `OPENROUTER_EMBEDDING_DIMENSIONS` (1536), `LOCAL_EMBEDDING_*` |
| Retrieval | `ATLAS_VECTOR_INDEX_NAME`, `VECTOR_CANDIDATE_MAX`, `VECTOR_NUM_CANDIDATES_MULTIPLIER`, `VECTOR_INDEX_HAS_BOOK_FILTER` |
| OCR | `OCR_ENABLED`, `OCR_PROVIDER`, `OCR_VISION_MODEL`, `OCR_LOCAL_LANGS`, `OCR_LOCAL_MIN_WORD_CONFIDENCE`, `OCR_MIN_TEXT_SCORE`, `OCR_DROP_BELOW_SCORE`, `OCR_RENDER_SCALE`, `OCR_MAX_PAGES`, `OCR_CONCURRENCY`, `OCR_MAX_OUTPUT_TOKENS` |
| Ingestion | `PROCESSING_CONCURRENCY`, `UPLOAD_MAX_MB`, `UPLOAD_MAX_FILES`, `INGESTION_MAX_DECOMPRESSED_MB` |
| Storage | `STORAGE_DRIVER`, `STORAGE_LOCAL_DIR`, `PDF_STORAGE_DIR`, `RECEIPTS_DIR`, `S3_*` |
| OMP | `OMP_BASE_URL`, `OMP_CONTEXT_PATH`, `OMP_API_TOKEN`, `OMP_USER_SECRET`, `OMP_SSO_SECRET`, `OMP_AUTHOR_GROUP_ID`, `OMP_SUBMISSION_GENRE_ID`, `OMP_PUSH_ENABLED`, `OMP_DEFAULT_COUNTRY` |
| Flipbook | `HEYZINE_CLIENT_ID`, `HEYZINE_API_KEY` |
| Web | `NEXT_PUBLIC_API_URL` |

> ⚠️ The live `.env` has historically kept **placeholder** `AUTH_JWT_SECRET`, `ADMIN_API_KEY` and `DEFAULT_ADMIN_PASSWORD`. Treat those as compromised until rotation is confirmed — see [[Open Threads]].
